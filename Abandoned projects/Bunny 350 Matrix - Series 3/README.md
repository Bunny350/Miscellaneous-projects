# Bunny 350 Matrix - Series 3
This folder contains the be-supposed last ever of my command creations, before I leave the command creations industry forever.
This project was supposed to be released in 2018, only to be delayed seveal times to indefinite. During that time, it got its minimum required game versions updated.
The project's featured build is the multi-function rabbit matrix, where it is utilized by datapacks... only to be found out that it just controls the command block. Whoops.
[Download it as archive](https://download-directory.github.io?url=https://github.com/Bunny350/Miscellaneous-projects/tree/main/Abandoned%20projects/Bunny%20350%20Matrix%20-%20Series%203)
By using this project, you may need to agree to [the maps and legacy projects policies](https://www.oitswilliam.com/oitswilliam-pang-minecraft-maps-and-legacy-projects-policies.html).
## Requirements
* Specific Minecraft JE version 1.20.6.
    *      If used in earlier versions, commands in the blocks will be removed, and the map will never function commands.
## Well-known issues
* Because of the minimum game version update, it caused image map rendering issues, where the assets refused loading, even when they were placed in zones that are meant to be rendered or was viewable in map data viewers.
* Resource packs are not being used as they were using the dated `pack_version`.
* Paintings resource `paintings_kristoffer_zetterstrand.png` used, but because Bunny 350 Matrix * Series 3 is made for versions beyond 1.12, it was unused.[^wiki]
